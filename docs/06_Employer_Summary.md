# 06 - Employer Summary

## Projekt in einem Satz

In einem lokalen Lab wurde ein fehlgeschlagener Netzwerk-Login gegen einen Windows-Host simuliert, von Wazuh erkannt und ueber einen Webhook automatisch an Shuffle SOAR zur Reaktionsbearbeitung weitergeleitet.

## Warum das Projekt relevant ist

Das Projekt zeigt nicht nur einzelne Tools, sondern einen kompletten Security-Prozess:

1. Ereignis entsteht auf einem Endpoint
2. Agent sammelt und uebertraegt Logs
3. SIEM erkennt und priorisiert den Vorfall
4. Alert wird an SOAR weitergegeben
5. Workflow startet eine strukturierte Reaktion

## Nachweisbare technische Kompetenzen

- Aufbau einer virtuellen Laborumgebung mit mehreren Systemrollen
- Netzwerk- und IP-Troubleshooting zwischen Host, VM und Docker
- Konfiguration eines Wazuh Windows-Agenten
- Analyse von Login-Fehlern im Wazuh Dashboard
- Integration von Wazuh mit Shuffle ueber Webhook
- sichere SOAR-Demo ohne riskante automatische Sperrung
- technische Dokumentation mit Screenshots, Befehlen und Fehlerbehebung

## Ergebnis fuer ein Bewerbungsgespraech

Dieses Projekt eignet sich gut, um praktische Grundlagen in Blue Teaming, SIEM-Betrieb und SOAR-Automatisierung zu zeigen. Besonders stark ist, dass nicht nur der Erfolgsfall dokumentiert wurde, sondern auch reale Troubleshooting-Schritte wie falsche Manager-IP, Docker-Erreichbarkeit und Portproxy-Konfiguration.
